# XTAP Fabric — Agent Examples

This repository contains standalone agent examples demonstrating [XTAP Fabric](https://github.com/xtap-io/xtap-fabric) integration patterns. Each example lives in its own folder with its own README and can be run independently.

## Examples

| Folder | Description | Status |
|--------|-------------|--------|
| [sre-agent](./sre-agent/) | Multi-service SRE debugging demo — baseline (no Fabric) | ✅ Step 1 complete |

## Adding New Examples

Each example should:

1. Live in its own top-level folder (e.g. `my-agent-example/`)
2. Include a `README.md` with prerequisites, how to run, and what to observe
3. Be self-contained with its own dependencies and docker-compose (if applicable)
